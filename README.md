# Tecno jogos

um site com o objetivo de proporcionar uma experiência de jogatina leve e em diferentes temas
o site tem os seguintes jogos para serem jogados:

# VolleyBound

um jogo de volêi dinâmico que pode ser jogado multiplayer local em diferentes lugares, em que
o jogo tem um modo torneio com 3 partidas que a dificuldade é aumentada gradualmente.

# Minecraft

um jogo de experiência de mundo aberto que proporciona uma gama de opções de conteúdo para 
construção e exploração.

# Dino Game

O clássico jogo do dinossauro do google, pule, corra e ganhe pontos. O princpal ponto é
você se divertir enquanto escapa dos pássaros ee cactos.

# Snake Game

um outro clássico dos jogos, ande pelo campo comendo e aumentando o próprio tamanho, mas 
cuidado com as paredes, elas podem te fazer começar toda sua jornada de novo.

# Hook Shot

se balance pelas cordas e chegue ao final de cada fase, a cada vez que avança você pode
ganhar novas decorações e terminar as fases com grande estilo.

# Pac-Man

explore os labirintos colete os pontos e fuja dos fantasmas, a cada vez a dificuldade dos
fantasmas aumenta, mas tem uma forma de pegá-los, jogue e descubra.

# Block Blast

encaiche blocos, monte sua estratégia para adiquirir números enormes de pontos, mas cuidado
o mesmo bloco que poderia te dar pontos pode fazer você perder tudo.

# O Jogo Mais Difícil

dedos rápidos! Esse jogo vai procurar toda sua atenção e habilidade, cada fase um desafio
e a cada tentativa uma nova estratégia
